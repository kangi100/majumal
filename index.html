마이크 상태

확인하는 중…

  • 안드로이드·PC는 크롬, 아이폰은 사파리에서 열어 주세요.
  • 처음 마이크를 누를 때 뜨는 권한 창에서 허용을 눌러 주세요.
  • https 주소로 열어야 마이크가 켜져요. 저장된 파일이나 다른 앱 안에 띄운 화면에서는 막힐 수 있어요.
  • 아래쪽 아이콘을 누르면 이름이, 길게 누르면 설명이 나와요. 길게 누를 때는 실행되지 않아요.
  • 마이크가 안 될 때도 키보드 버튼을 누르고, 키보드의 마이크(음성 입력)로 받아쓰기를 할 수 있어요.

마이크 허용 창이 매번 뜰 때

대부분 ‘이번만 허용’으로 되어 있어서 그래요. 아래를 한 번만 바꿔 두면 다음부터 묻지 않아요.

  1. 권한 창이 뜨면 ‘이번만 허용’ 말고 ‘사이트 방문 시 허용’(또는 ‘허용’)을 누르세요.
  2. 크롬 주소창 왼쪽 아이콘 → 권한 → 마이크를 허용으로 바꿔요. 크롬 메뉴(⋮) → 설정 → 사이트 설정 → 마이크에서 이 사이트를 허용으로 바꿔도 돼요.
  3. 휴대폰 설정 → 애플리케이션 → Chrome → 권한 → 마이크가 ‘매번 확인’이면 ‘앱 사용 중에만 허용’으로 바꿔요. 삼성폰에서 자주 생겨요.
  4. 아이폰은 사파리 주소창 aA → 웹사이트 설정 → 마이크 → 허용, 또는 설정 → 앱 → Safari → 마이크 → 허용으로 바꿔요.
  5. 시크릿 탭은 닫을 때마다 권한이 초기화돼요. 일반 탭에서 열어 주세요.
